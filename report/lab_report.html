2. Setup procedure

Everything is driven by scripts/lab_setup.sh, which is in the repository. From a fresh VM, two commands reproduce the full stack:

cd ~/workspace
git clone https://github.com/callmejei/mlops_2025ae05470_assignment.git
bash mlops_2025ae05470_assignment/scripts/lab_setup.sh 2>&1 | tee ~/workspace/lab_setup.log
#StageWhat the script does
1Python environmentCreates ~/.venvs/heart and installs requirements.txt
2CI pipelineRuns scripts/ci_local.sh: flake8 → pytest → download & clean → EDA → train with MLflow → docker build → container smoke test. Stops at the first failure.
3Docker ComposeStarts API :8010, Prometheus :9095, Grafana :3005 and waits for /health
4Kubernetesminikube start, minikube image load, kubectl apply -f k8s/deployment.yaml, rollout status
5LoadBalancerRuns minikube tunnel in the background so LoadBalancer services get an external IP
6HelmInstalls Helm if missing, then helm upgrade --install heart-api helm/heart-api
7MLflow UIStarts the tracking UI on :5005 in the background
8VerifyPOSTs sample_request.json to all three endpoints
